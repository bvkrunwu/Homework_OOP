## Архитектура классов

В систему добавлен **абстрактный базовый класс** `BaseProduct` и **миксин** `PrintMixin`, которые расширяют функциональность и обеспечивают единообразие реализации.

---

## Класс `BaseProduct` (абстрактный базовый)

**Назначение**: определяет контракт для всех классов‑продуктов, обеспечивая типовую безопасность и стандартизированный интерфейс.

**Наследование**: наследуется от `ABC` (Abstract Base Class) из модуля `abc`.

### Ключевые особенности

- **Абстрактность**: нельзя создать экземпляр напрямую — только через наследников.
    
- **Инкапсуляция**: цена (`__price`) хранится как приватный атрибут.
    
- **Контракт**: обязательные методы и свойства, которые должны быть реализованы в подклассах.
    

### Атрибуты и методы

- **`__init__(name, description, price, quantity)`**  
    Инициализирует базовые атрибуты продукта.
    
    - `name`: название.
        
    - `description`: описание.
        
    - `__price`: цена (приватная).
        
    - `quantity`: количество на складе.
        
- **`new_product(cls, *args, **kwargs)`** (classmethod, абстрактный)  
    Метод для создания или обновления продукта. Должен быть реализован в подклассах.
    
- **`__add__(self, other)`** (абстрактный)  
    Определяет сложение двух продуктов (по общей стоимости). Требует реализации в наследниках.
    
- **`price`** (property, абстрактный геттер)  
    Возвращает текущую цену продукта.
    
- **`price.setter`** (абстрактный сеттер)  
    Устанавливает цену с валидацией (например, проверка на положительность).
    
---

## Миксин `PrintMixin`

**Назначение**: добавляет логирование создания объектов с выводом информации в консоль.

### Особенности

- **Гибкость**: может быть применён к любому классу через множественное наследование.
    
- **Автоматичность**: выводит информацию при инициализации объекта.
    

### Метод

- **`__init__(self, *args)`**
    
    - Вызывает родительский `__init__` через `super().__init__(*args)`.
        
    - Печатает имя класса и аргументы инициализации в формате:
        
        ```
        ClassName(arg1, arg2, ...)
        ```
        

### Пример использования

```
class Smartphone(BaseProduct, PrintMixin):
    # Реализация как выше

# При создании экземпляра:
smartphone = Smartphone(
    name="Samsung Galaxy S23 Ultra",
    description="256GB, Серый цвет, 200MP камера",
    price=180000.0,
    quantity=5,
    efficiency=95,
    model="S23 Ultra",
    memory="256 GB",
    color="Серый"
)
# Вывод в консоль:
# Smartphone('Samsung Galaxy S23 Ultra', '256GB, Серый цвет, 200MP камера', 180000.0, 5, 95, 'S23 Ultra', '256 GB', 'Серый')
```

## Влияние на существующие классы

NaN. **`Product`**
    
    - Теперь должен наследоваться от `BaseProduct` и реализовывать все абстрактные методы/свойства.
        
    - Пример:
        
        ```
        class Product(BaseProduct):
            @classmethod
            def new_product(cls, *args, **kwargs):
                return cls(*args, **kwargs)
        
            def __add__(self, other):
                if type(self) is not type(other):
                    raise TypeError("Нельзя складывать товары разных категорий")
                return self.price * self.quantity + other.price * other.quantity
        
            @property
            def price(self):
                return self.__price
        
            @price.setter
            def price(self, value):
                if value <= 0:
                    raise ValueError("Цена должна быть положительной")
                self.__price = value
        ```
        
`Smartphone` и `LawnGrass`
    
    - Должны наследоваться от `BaseProduct` и `PrintMixin`.
        
    - Реализуют абстрактные методы согласно своей специфике.
        

---

**Примечание**:

- `PrintMixin` можно подключать к любым классам, требующим логирования создания.
    
- Все подклассы `BaseProduct` обязаны реализовать абстрактные методы, иначе возникнет ошибка `TypeError` при попытке создания экземпляра.



#  Класс `Product`

Класс `Product` предназначен для представления отдельного товара в системе. Каждый экземпляр класса содержит всю необходимую информацию о товаре: его название, описание, цену и количество на складе.

###  Атрибуты класса:

- `name`: строка, представляющая название товара.
- `description`: строка, описывающая товар.
- `price`: вещественное число, указывающее цену товара.
- `quantity`: целое число, определяющее количество товара на складе.

###  Пример использования:

```python
product = Product(
    name="Samsung Galaxy S23 Ultra",
    description="256GB, Серый цвет, 200MP камера",
    price=180000.0,
    quantity=5
)
```

Дополнение функционала к классу `Product`

В систему добавлены **два подкласса** для специализированного представления товаров: `Smartphone` и `LawnGrass`. Это позволяет учитывать специфические характеристики отдельных категорий продукции при сохранении общей структуры базового класса.

## Общие принципы реализации

- **Наследование**: оба подкласса используют `super().__init__()` для инициализации базовых атрибутов.
    
- **Типовая безопасность**: методы `__add__` проверяют совместимость типов перед выполнением операций.
    
- **Расширяемость**: структура позволяет легко добавлять новые категории товаров.
    

## Класс `Smartphone` (наследник `Product`)

Предназначен для представления смартфонов.

### Новые атрибуты

- `efficiency` — характеристика производительности (например, балл теста).
    
- `model` — модель устройства.
    
- `memory` — объём памяти (например, `"256 GB"`).
    
- `color` — цвет корпуса.
    

### Метод `__add__`

Обеспечивает безопасное сложение экземпляров:

- Проверяет, что оба объекта имеют тип `Smartphone`.
    
- При несовпадении типов выбрасывает `TypeError` с сообщением:
    
    ```
    "Нельзя складывать товары разных категорий"
    ```
    
- При совместимости типов делегирует сложение базовому классу.
    

### Пример создания экземпляра

```
smartphone = Smartphone(
    name="Samsung Galaxy S23 Ultra",
    description="256GB, Серый цвет, 200MP камера",
    price=180000.0,
    quantity=5,
    efficiency=95,
    model="S23 Ultra",
    memory="256 GB",
    color="Серый"
)
```

## Класс `LawnGrass` (наследник `Product`)

Предназначен для представления газонных трав.

### Новые атрибуты

- `country` — страна происхождения семян.
    
- `germination_period` — срок прорастания (например, `"7–14 дней"`).
    
- `color` — цвет травы (например, `"Изумрудно‑зелёный"`).
    

### Метод `__add__`

Аналогичен реализации в `Smartphone`:

- Проверяет тип второго объекта.
    
- При несоответствии выбрасывает `TypeError`.
    
- В случае совместимости вызывает сложение через `super().__add__(other)`.
    

### Пример создания экземпляра

```
grass = LawnGrass(
    name="Мятлик луговой",
    description="Теневыносливый газон, устойчив к вытаптыванию",
    price=1500.0,
    quantity=20,
    country="Россия",
    germination_period="10–14 дней",
    color="Изумрудно‑зелёный"
)
```

### Повышение надежности при создании товаров

Теперь при создании экземпляра класса `Product` выполняется автоматическая проверка значения параметра `quantity` (количество товара). Если передано нулевое значение, возникает исключение `ValueError` с информативным сообщением:

> **Товар с нулевым количеством не может быть добавлен**

Это гарантирует невозможность добавления в каталог товаров с неопределённым запасом и защищает приложение от некорректных состояний базы данных.

#### Пример возникновения исключения:

python

Копировать

```python
try:
    invalid_product = Product(
        name="Некорректный товар",
        description="Тестовый продукт",
        price=1000.0,
        quantity=0  # Неверное значение!
    )
except ValueError as e:
    print(e)  # Выведет: Товар с нулевым количеством не может быть добавлен
```

Таким образом, любое создание товара с недопустимым значением количества немедленно прерывает выполнение операции и уведомляет пользователя о причине ошибки.

#  Класс `Category`

Класс `Category` служит для группировки товаров по категориям. Каждая категория имеет уникальное название, описание и список товаров, входящих в нее. Помимо этого, класс содержит два статических атрибута для учета общего количества созданных категорий и товаров.

###  Атрибуты класса:

- `name`: строка, представляющая название категории.
- `description`: строка, описывающая категорию.
- `products`: список объектов класса `Product`, относящихся к данной категории.
- `category_count`: статический атрибут целого типа, хранящий общее количество созданных категорий.
- `product_count`: статический атрибут целого типа, хранящий общее количество товаров во всех категориях.

###  Пример использования:

```python
category = Category(
    name="Смартфоны",
    description="Смартфоны, как средство не только коммуникации, но и получения дополнительных функций.",
    products=[
        product1,
        product2,
        product3
    ]
)
```

Расчёт среднего ценника товаров в категории

Реализован удобный метод `middle_price()`, предназначенный для быстрого расчёта средней стоимости всех товаров в заданной категории. Этот метод обеспечивает гибкую и отказоустойчивую работу даже в ситуациях, когда категория пуста.

#### Алгоритм работы метода:

1. Получает список всех товаров в категории методом `get_products()`.
2. Суммирует цены всех имеющихся товаров.
3. Производит деление суммы на количество товаров.
4. Если товаров нет (делить на ноль недопустимо), возвращается значение `0`.

Такой подход устраняет риск аварийного завершения программы и упрощает интеграцию метода в интерфейсы управления товарами.

#### Пример использования метода:

python

Копировать

```python
category = Category(
    name="Электроника",
    description="Разнообразные электронные гаджеты",
    products=[...]  # Список товаров
)

average_price = category.middle_price()
print(f"Средняя цена в категории '{category.name}': {average_price:.2f} рублей")
```

Этот метод особенно полезен для аналитики продаж и формирования динамических ценовых предложений клиентам.
